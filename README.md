# Два контроллера на ESP8266

В репозитории содержатся два скетча. Они предназначены для совместной работы и обеспечивают управление воротами через Telegram и бесконтактные карты.

## first_esp
Первая плата подключается к Wi‑Fi, авторизуется в Telegram и хранит список карт во встроенной файловой системе SPIFFS. При помощи UDP широковещательных сообщений плата ищет вторую ESP и запоминает её IP‑адрес. Через HTTP она отправляет ей актуальный список карт и команды на открытие ворот.

Основные возможности:
- добавление и удаление карт через Telegram;
- хранение списка карт с привязкой имени и срока действия;
- управление списком пользователей (админы и гости);
- выдача гостевого доступа с ограниченным сроком;
- открытие ворот по команде из Telegram;
- синхронизация списка карт со второй платой;
- веб‑страница для настройки Wi‑Fi и токена бота;
- автоматический поиск второй платы при старте или потере связи.

## second_esp
Вторая плата управляет реле и считывает RFID‑карты. Она также ищет первую плату по UDP. При получении списка карт сохраняет его в SPIFFS и использует для проверки предъявленных карт. При успешном чтении разрешённой карты либо по команде с первой платы плата включает реле для открытия ворот и издаёт звуковой сигнал.

Поддерживаемые функции:
- хранение списка UID карт;
- выдача UID считанной карты первой плате для добавления в базу;
- открытие ворот по HTTP запросу;
- автоматический обмен приветственными сообщениями по UDP для нахождения IP.

## Настройка
1. Скомпилируйте и залейте скетч `first_esp` на одну ESP8266, `second_esp` — на другую.
2. После первой загрузки перейдите на web‑страницу первой платы и укажите параметры Wi‑Fi и токен Telegram‑бота.
3. Обе платы должны находиться в одной сети. Они самостоятельно найдут друг друга и начнут обмениваться данными.
4. Для выдачи доступа новым пользователям используйте команду `/grant-ID-role-hours` от имени администратора,
   например `/grant-123456-guest-6`.
   Отклонить запрос можно командой `/reject-ID`.
   Пользователь запрашивает доступ через `/request`.

Все комментарии в коде приведены на русском языке для лучшего понимания работы.
