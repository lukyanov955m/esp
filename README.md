# Два контроллера на ESP8266

В репозитории находятся два примера скетчей для работы с автоматическими воротами.
Первая плата (`first_esp`) общается с Telegram‑ботом, хранит список карт и
передает команды второй плате. Вторая плата (`second_esp`) подключена к
считывателю RFID и реле управления воротами.

Обе платы автоматически ищут друг друга в локальной сети с помощью UDP
широковещательных сообщений. Если IP устройства изменился, оно вновь будет
найдено и запомнено.

## Основные возможности
- Управление воротами через Telegram
- Передача списка карт на вторую плату
- Получение UID карты от второй платы при добавлении
- Работа со списком карт в SPIFFS

Перед загрузкой скетчей укажите параметры Wi‑Fi и токен Telegram‑бота.
