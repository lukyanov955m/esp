# Инструкции для Codex

- Все комментарии в исходниках и README пишем по-русски.
- Изменения в коде располагаются в папках `first_esp` и `second_esp`.
- Перед коммитом проверяйте состояние репозитория командой `git status --short`.
- Автоматических тестов нет, убедитесь, что скетчи компилируются в Arduino IDE.
